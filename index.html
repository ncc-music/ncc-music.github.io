    Acerca de Este Proyecto

    Un reproductor de audio moderno

    Este sitio web te permite reproducir archivos de audio de alta calidad en formatos FLAC y WAV directamente desde tu navegador. Diseñado para los audiófilos que valoran la calidad del sonido.

    Características:

    • ✅ Soporte para FLAC, WAV, MP3 y OGG
    • ✅ Carga de múltiples archivos
    • ✅ Control de volumen
    • ✅ Modo shuffle y repeat
    • ✅ Visualizador de progreso
    • ✅ Interfaz responsiva
